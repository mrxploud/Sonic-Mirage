# BIOS

Este projeto **não inclui** BIOS. Coloque aqui os seus próprios arquivos, com exatamente estes nomes:

| Arquivo | Console | Observação |
|---|---|---|
| `bios_CD_U.bin` | Sega CD (americano) | 131.072 bytes. Obrigatório: o Sega CD não roda sem BIOS. |
| `sega_101.bin` | Sega Saturn (japonês, v1.01) | 524.288 bytes. Usado pelo núcleo Beetle Saturn para discos japoneses. |
